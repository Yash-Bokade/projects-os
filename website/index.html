Engineered for Speed & Portability

Hyprland + Niri Switcher

Both Wayland compositors pre-installed and synced to your unified themes and hotkeys. Press F2 at login to switch anytime.

Auto 15 GB Persistence

Flash with Rufus in DD Mode. On first boot, Projects OS automatically formats a 15 GB ext4 persistence partition in the remaining free USB space.

First-Boot Stack Wizard

Connects Wi-Fi/Ethernet first, then installs latest Java, Rust, Go, C/C++, Node.js, or Python via mise and wires LSPs straight into LazyVim.

Project Reset Only

Done with a project and pushed to GitHub? Reset wipes ~/Projects, language runtimes, and browser sessions while keeping Wi-Fi, SSH keys, and OS settings.

Minimal Curated Apps

Minimal-UI Firefox, Neovim (LazyVim), Git, OpenSSH, LocalSend for instant LAN file sharing, and OBS Studio with Wayland hardware capture.

Total GUI Customization

Native GTK4 Settings app edits matte themes, live hotkeys for both compositors, OBS/LocalSend export paths, and generates ~/SHORTCUTS.txt.

3-Step Rufus Setup (32 GB USB)

01

Download Automated ISO

Grab projects-os-x86_64.iso (~2.5 GB) built automatically by GitHub Actions on every push to main.

02

Flash via Rufus (DD Mode)

Select your SanDisk 32 GB drive in Rufus, pick the ISO, click Start, and select Write in DD Image mode.

03

Boot & Code

Boot with Secure Boot disabled. Login with dev / projects. Your 15 GB persistence partition initializes automatically.
